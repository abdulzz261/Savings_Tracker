## ✨ Fitur Utama
* **Smart Savings Tracker:** Pencatatan target tabungan utama beserta perhitungan persentase progres.
* **Gamification Level System:** Milestone pencapaian level berdasarkan persentase saldo terkumpul.
* **Estimation Calculator:** Fitur kalkulasi otomatis untuk melihat estimasi waktu pencapaian target.
* **Interactive UI Modals:** Fitur konfirmasi aksi sensitif (Reset Data), validasi input otomatis, dan sistem *cooldown edit lock* (24 jam).
* **State Retention / Offline-First:** Penyimpanan data lokal (*browser LocalStorage*) untuk memastikan akses data cepat tanpa latency.
